# 影子科技数据下载器（yingzi-downloader）

影子科技（扬翔）养殖平台的数据批量下载工具，Windows 桌面程序。在一个窗口里设置好条件，程序自动打开浏览器、登录、进入页面、筛选、导出，下载的文件按条件命名。不用一遍遍手动点网页。

> 需要有影子科技平台的账号才能使用。本工具是个人编写的自动化脚本，与影子科技官方无关；平台页面改版后可能需要更新。

## 功能

一个窗口完成六种下载，各种任务可以放进同一个任务列表一次跑完。全程只开一个浏览器、只登录一次。

| 功能 | 平台 | 主要条件 | 说明 |
|---|---|---|---|
| 母猪综合查询 | 养殖生产 · 统计报表 | 日期字段（配种 / 分娩 / 断奶等）+ 日期范围 | 超过单次导出上限（5 万条）时自动按日期拆分成多段 |
| 猪只转移 | 养殖生产 · 养殖公共 | 所在场 + 转移年月 | 逐条导出每张转移单的详情，生成转移记录清单和汇总表；中断后可续传 |
| 母猪档案 | 养殖生产 · 个体养殖 | 阶段（后备/生产、仔猪/保育/待售）+ 所在场 | 在表格里追加「场」「阶段类型」列和下载信息 |
| 遗传性状查询 | 基因组选种 · 生长性状 | 测定猪场 + 结测日期 + 国标编码 | 国标编码超过 400 个时分批查询后合并 |
| 育种值查询 | 基因组选种 · 按个体 | 国标编码 | 每批 400 个，分批后合并 |
| 系谱查询 | 基因组选种 · 系谱信息 | 国标编码 × 场列表 × 在场 / 离场 | 循环查询，查全后合并 |

其他功能：

- **记住登录状态**：登录一次后，下次启动通常免登录。
- **后台运行**：不显示浏览器窗口。
- **定时下载**：保存下载计划，用 Windows 计划任务每天或每周自动运行。
- **自动判断等待**：按页面加载和网络请求判断何时进行下一步，不靠固定等待；失败自动重试。
- **下载记录**：每种下载在下载目录里各有一份「×× 下载记录.csv」，记录条件、条数和文件名。
- **出错现场**：出错时把截图和页面源码保存到 `debug` 文件夹，便于排查。

## 下载使用

1. 到 [Releases](https://github.com/tony2015116/yingzi-downloader/releases/latest) 下载 `yingzi-downloader-windows.zip`，解压到一个固定的文件夹。
2. 双击 `影子科技数据下载器.exe`。电脑上需要装有 Chrome 或 Edge 浏览器。
3. 填入账号密码。也可以把 `.env.example` 改名为 `.env`，填入账号密码，启动时会自动读取。
4. **第一次运行**：先不要勾选「后台运行」，登录一次（有验证码时在浏览器里手动完成），并勾选「记住登录状态」。之后就可以后台运行和定时下载。

程序会在自己所在的文件夹里生成这些文件，不要把程序放在会被清理的临时目录：

| 文件 / 文件夹 | 内容 |
|---|---|
| `browser_profile` | 浏览器登录缓存 |
| `debug` | 出错截图和页面源码 |
| `影子科技下载器设置.json` | 界面上的设置、任务列表、定时计划 |
| `影子科技下载器.log` | 运行日志 |

`.env`、`browser_profile` 里有账号信息，发给别人时请删掉。

### 命令行自动模式

批处理或计划任务使用，载入任务后自动开始：

```bat
影子科技数据下载器.exe --report "配种日期,2026-10-01,2026-10-08"
影子科技数据下载器.exe --transfer "信宜场,2026-06,2026-07"
影子科技数据下载器.exe --sow "龙马一场,1;龙马一场,2"          :: 1=后备/生产 2=仔猪/保育/待售
影子科技数据下载器.exe --genetic "某测定猪场,2026-08,2026-09" --genetic-codes 国标编码.txt
影子科技数据下载器.exe --ebv-codes 国标编码.txt
影子科技数据下载器.exe --ped-codes 国标编码.txt --ped-farms "龙马一场;龙马二场" --ped-status 在场
影子科技数据下载器.exe --run-schedule                           :: 按保存的定时计划运行一次
```

加 `--headless` 为后台运行。完整说明见 `app_gui.py` 文件开头。

## 从源码运行和打包

需要 Python 3.8 或以上（Windows）。

```bat
pip install -r requirements.txt
python app_gui.py          :: 直接运行
build.bat                  :: 打包成 dist\影子科技数据下载器.exe
```

`build.py` 的选项：`--onedir`（文件夹版，启动更快、杀毒软件误报更少）、`--console`（带控制台窗口，排查问题用）、`--no-install`（跳过安装依赖）。

### 发布新版本

推送 `v` 开头的标签，GitHub Actions 会在 Windows 上自动打包并发布到 Releases：

```bash
git tag v1.0.1
git push origin v1.0.1
```

在仓库的 Actions 页面手动运行「打包 Windows exe」，只打包不发布，exe 在运行结果的 Artifacts 里下载。

## 代码结构

| 文件 | 作用 |
|---|---|
| `app_gui.py` | 统一界面（Tkinter），程序入口 |
| `yz_core.py` | 公共部分：浏览器、登录、等待与点击、网络请求监控、下载监控、任务重试 |
| `task_report.py` | 母猪综合查询 |
| `task_transfer.py` | 猪只转移 |
| `task_sowfile.py` | 母猪档案 |
| `task_genetic.py` | 遗传性状查询 |
| `task_ebv.py` | 育种值查询 |
| `task_pedigree.py` | 系谱查询 |
| `schedule_plan.py` | 定时下载（Windows 计划任务） |
| `ui_icons.py` | 界面图标 |
| `build.py` / `build.bat` | PyInstaller 打包脚本 |
